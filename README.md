# 🛒 Amazon Sales Insights Dashboard

An interactive business intelligence dashboard built using 
Microsoft Power BI, analyzing Amazon sales data to uncover 
payment trends, regional performance, seasonal sale patterns, 
and revenue insights across multiple years.

---

## 📌 Project Overview

This dashboard analyzes Amazon sales transactions to understand:
- How customers prefer to pay (Cash, Card, Online)
- Total payment amounts distributed across years
- Billing location distribution across regions
- Count of billing IDs to measure transaction volume
- Revenue performance during seasonal sales events
  (Diwali Sale, End-of-Season Sale, etc.)

---

## 📊 Dashboard Features

| Visual | Insight |
|---|---|
| Pie / Donut Chart | Payment method distribution (Cash, Card, Online) |
| Bar Chart | Sum of payment amount by year |
| Map / Count Chart | Billing location count by region |
| KPI Card | Total sum of payment amount |
| Count Visual | Total billing ID count |
| Comparison Chart | Seasonal sale performance (Diwali, WS Sale, etc.) |

---

## 🛠️ Tech Stack

- **Tool:** Microsoft Power BI
- **Data Handling:** Power Query (Data Cleaning & Transformation)
- **Database:** SQL (Amazon Sales Data)
- **Skills Applied:**
  - Data Modeling
  - DAX Measures and Calculated Columns
  - KPI Design
  - Interactive Slicers and Filters
  - Business Intelligence Reporting
